# SONORA — Design Decisions

## 1. Why this approach?

I chose the Premium Home Page track because I wanted to focus on creating a polished and engaging music-streaming experience. I designed SONORA with a strong hero section, clear value proposition, prominent call-to-action, playlist discovery sections, music controls, and responsive layouts.

I focused on visual hierarchy, spacing, typography, and restrained interactions so the page feels like a real product rather than a basic template. I also added a small hidden Easter egg triggered by double-clicking the SONORA logo to make the experience more engaging for users who explore the interface.

## 2. One trade-off

Because of the time limit, I prioritized the quality of the landing-page experience and responsive UI instead of building a complete music-streaming backend. I focused on making the main interface feel polished and functional.

With a full week, I would add real authentication, real music/API integration, persistent playlists, and more complete playback functionality.

## 3. AI usage

I used AI tools during development to help brainstorm UI ideas, improve component structure, debug issues, and refine parts of the implementation. I personally reviewed, tested, and modified the generated code to make sure it worked correctly with my project and matched the SONORA design.

I verified the final interface myself, including the main interactions, layout, content, and deployment. I can explain the implementation and design decisions made in the project.
